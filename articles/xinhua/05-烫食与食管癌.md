# 文章5：超过 65℃烫食热饮与食管癌

> **原文链接**：[点击查看微信原文](https://mp.weixin.qq.com/s/oX5mrYIvxJS7gfxFUYBouw)

## 📌 内容分析
1. **原理**：口腔、食管耐受温度不同，＞65℃反复烫伤食管黏膜，经历黏膜损伤→慢性炎症→癌前病变→食管癌；单次烫伤可修复，长期反复伤害才危险[cite: 5]。
2. **其他食管伤害诱因**：烟酒 + 烫食叠加、腌制熏烤重盐食物、吃饭过快[cite: 5]。
3. **食管癌 4 个早期预警信号**：胸骨后异物感、进食哽噎感、胸骨后闷胀隐痛灼烧、频繁嗳气胸口堵；区分普通胃食管反流和早期食管癌，介绍中晚期典型 “进行性吞咽困难”[cite: 5]。
4. **高危人群界定**：≥45 岁，高发地区居住、食管癌家族史、癌前病变、烫食烟酒习惯；**胃镜是早筛金标准**，给出不同食管病变（糜烂、增生、息肉）干预方式[cite: 5]。
5. **食管养护口诀**：不烫嘴、少腌霉、戒烈酒、远离烟，慢吃饭、控反流，45 岁做胃镜[cite: 5]。
