# 文章6：根茎类蔬菜秋补

> **原文链接**：[点击查看微信原文](https://mp.weixin.qq.com/s/AKLJmzvWV5xj8B9KaBTeMQ)

## 📌 内容分析
1. **根茎类蔬菜优势**：脾胃负担小、营养密度高、膳食纤维丰富，饱腹通便，适合秋天[cite: 5]。
2. **7 种食材功效**：山药（健脾）、红薯（通便）、芋头（易消化）、莲藕（生熟功效不同，润燥养胃）、荸荠（清热化痰）、白萝卜（消食解腻）、土豆（替代部分主食控体重）[cite: 5]。
3. **三类人群进补注意**：脾虚者先健脾；胃火旺盛先清胃火；老人儿童注重消食护胃[cite: 5]。
4. **特别提醒**：糖尿病患者食用薯类需要扣减主食，监测血糖[cite: 5]。
