# 文章182: 老年抗阻训练与肌少症

## 📌 核心内容

本文以 86 岁坚持举铁的张奶奶案例切入，破除老年人应当静养的固有认知，点明**肌肉是保障晚年生活质量的核心底气，抗阻训练是预防肌少症的有效手段**。

1. **案例启示**：张奶奶 70 多岁开始运动，坚持力量训练，86 岁生活完全自理。力量训练目的不是塑形，而是保住肌肉、维持自理能力。
2. **抗阻运动价值**：对老年人有七大益处：对抗肌少症、提升骨密度防骨折、保护关节、帮助控糖、改善平衡减少跌倒、维持日常自理能力、调节情绪保护认知。
3. **5 个居家简易动作**：矿泉水瓶弯举、弹力带侧抬腿、椅子深蹲、单脚站立、平板支撑。
4. **注意事项**：每周 3～4 次，强度循序渐进；发力呼气、放松吸气，禁止憋气；优先练习平衡训练，再练力量。
