第240篇 甜玉米消费提示
https://mp.weixin.qq.com/s/yeNTy5cq_QKa-l1jqISfww
主要内容
本文是甜玉米消费提示，解答大家对甜玉米甜度、主食替代、血糖、维 C 的疑问：1. 甜玉米甜味来自蔗糖，淀粉含量低，超甜品种含糖可达 20%~30%，短时间加热甜度还会小幅提升；2. 甜玉米属于跨界主食，可以替代米饭，同等重量下碳水和热量低于米饭，一根约等于 1/2～2/3 份米饭，食用后其他主食要减量；3. 甜玉米 GI 值 55，远低于白米饭，膳食纤维丰富，升糖速度平缓，不会造成血糖快速飙升；4. 甜玉米维 C 含量较高，高于番茄，生吃补维 C 效果好；加热会造成维 C 流失，规范速冻保存的甜玉米维 C 保留更好。
关键词
甜玉米、蔗糖、淀粉、跨界主食、碳水、升糖指数 GI、血糖、维生素 C、速冻玉米
